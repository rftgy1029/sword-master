# S’word Master

티어 단어리스트를 게임처럼 학습하는 학교 자율 영단어 학습도구 개발 프로젝트입니다.

## 목표

- 단기: 2026년 2학기 기말고사 준비
- 장기: 2027년 수능까지 이어서 사용할 수 있는 학습도구 개발

## 논의 중인 구현 방향

- Flutter Web 기반 데스크톱 화면 우선 구현
- 실버 단어장 290개 항목 중 30개로 초기 검증
- 학습 범위 선택, 뜻·유의어·반의어 퀴즈, 학습 기록과 약점 복습
- 짧은 문제 세트, 즉시 피드백, 점수와 재도전을 활용한 게임형 학습

티어는 선생님이 정한 누적 학습 범위입니다. 세부 게임 규칙, 역할과 개발 일정은 팀 논의 후 결정합니다.

## 현재 상태

기획 단계이며, 구현 방향은 아직 논의 중입니다. 기획안 제목은 **영어 단어앱 기획안**입니다.
