# S’word Master — React 웹게임

현재 개발 소스는 **React + Vite + JavaScript + CSS**입니다. 기존 시작 화면과 픽셀 던전을 유지하면서 티어 선택 → 경로 선택 → 영어 퀴즈 카드 전투 → 보상·강화 → 보스·결과까지 플레이할 수 있습니다. 단어장 전체 1,000개, 화면 설정, 기존 메뉴 조작을 유지합니다. [v0.6 전투 규칙·저장·검증 기록](docs/deckbuilding-v0.6.md).

## 실행

Node.js 20.19+ 또는 22.12 이상이 필요합니다. 이 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

개발 주소: `http://127.0.0.1:8175/`. 종료는 터미널에서 Ctrl+C입니다.

배포용 파일 생성과 확인:

```sh
npm run build
npm run preview
```

미리보기 주소: `http://127.0.0.1:8176/`. `dist/`가 배포할 파일입니다. 학교에서 사용할 공개 주소는 아직 없습니다. 원본 소스는 Vite를 통해 실행하며, Python 서버로 원본 JSX를 직접 제공하지 않습니다.

## 파일 역할

- `src/main.jsx`: React 시작점과 StrictMode.
- `src/App.jsx`: 시작 화면과 메뉴 선택 상태, 키보드 이동.
- `src/menuNavigation.js`: 창·탭 전환이나 배경 클릭 후에도 마지막 선택에서 키보드 조작을 이어가는 입력 처리.
- `src/components/AdventureDialog.jsx`: 티어·경로·전투·보상·휴식·대장간·덱·유물·결과 화면.
- `src/components/CombatScene.jsx`, `QuizPanel.jsx`, `ReviewDialog.jsx`: 기존 용사 그림을 재사용한 전투 장면, 퀴즈·해설, 약점 복습과 학습 현황.
- `src/game/engine.js`, `catalog.js`, `random.js`: 턴·카드·유물·적 행동·보상·경로 생성과 재현 가능한 난수.
- `src/game/quiz.js`: 기존 단어에서 선택지까지 검토한 72개 단어·120개 뜻/유의어/반의어 문제. 티어별 누적 범위를 지킵니다.
- `src/game/storage.js`, `useProgress.js`: 학습·클리어·현재 모험을 함께 저장하고, 손상 데이터와 다른 탭 충돌 시 원본을 보존합니다.
- `src/components/TitleScene.jsx`: Canvas 애니메이션 연결. 컴포넌트가 사라지면 AbortController로 루프·이벤트를 정리합니다.
- `src/components/SettingsDialog.jsx`: 화면·연출 설정과 조작 안내. 즉시 반영, 전체 화면 전환, 기본값 복원, 키보드 이동과 초점 복귀.
- `src/components/VocabularyDialog.jsx`: 티어별 단어장, 누적·추가 범위 전환, 검색, 상세 설명과 페이지 이동.
- `src/vocabulary.js`, `src/data/vocabulary.json`: 원자료 1,000개 항목과 누적 티어·검색 처리.
- `src/settings.js`: 설정값 검증과 버전이 있는 브라우저 저장. 학습 기록과 별도의 키를 사용합니다.
- `src/scene.js`: 384×288 픽셀 격자 위의 벽·문·바닥·용사·망토·횃불. 정적 배경은 한 번 그려 재사용하고, 작은 망토와 불빛만 갱신합니다. 큰 배경 이미지에 의존하지 않습니다.
- `styles.css`: 배치·글꼴·선택 메뉴의 3.2초 밝기 변화·작은 창 대응.
- `src/components/adventure.css`: 기존 팔레트와 글꼴을 공유하는 모험 화면, 모바일과 움직임 줄이기 대응.
- `assets/`: 공개 글꼴과 이전 버전의 이미지 보관본. 현재 메인 화면은 글꼴만 불러오며 이전 배경 이미지는 배포 빌드에서 참조하지 않습니다.
- `public/licenses/`: 배포 파일에도 포함되는 글꼴 OFL 라이선스.
- `package-lock.json`: 실제 설치한 의존성 버전을 고정한 기록. 팀에서는 `npm ci`로 동일하게 설치할 수 있습니다.

## 구현 범위와 확인

새 모험에서 다섯 티어를 선택하고 8층 던전에 입장합니다. 3 에너지·5장 드로우로 턴을 진행하고, 카드 선택 즉시 비용을 소비한 뒤 단어 문제를 맞히면 효과가 발동합니다. 보상 카드·유물, 휴식의 회복/무료 강화, 금화를 사용하는 카드/유물 강화와 상점, 보스 승리의 영구 카드 해금을 지원합니다. 학습·약점·클리어 기록은 도전이 끝나도 유지됩니다.

이어하기는 저장된 모험이 있을 때 활성화됩니다. 퀴즈가 열린 상태와 해설 상태도 복구합니다. 기존 설정 키와 원본 단어 데이터를 변경하지 않으며, 모험은 새 키 `sword-master.adventure.v1`에만 저장합니다. 저장 실패는 화면에서 안내하고, 손상된 원본이나 다른 탭의 새 기록을 덮어쓰지 않습니다. 계정/서버 동기화는 없습니다.

자동 검사 45개가 통과했습니다. 이 환경에서는 개별 검사 결과를 확인하기 위해 `node --test --test-isolation=none --test-reporter=spec`도 실행했습니다(Node 22.8+). 300개 시드의 경로와 5개 티어×3개 시드의 전체 모험에서 매 행동마다 저장·복구를 검사합니다. Chromium에서 실제 UI로 오답·복습·이어하기·강적·보상·카드/유물 강화·카드 구입·보스 해금과 360px 화면을 확인했습니다. 전체 자료의 퀴즈 검수, 교실 플레이테스트와 장기 밸런스 조정은 남아 있습니다.

이하에는 이전 UI 버전의 구현·검증 기록을 보관합니다.

React 19.3.1, React DOM 19.3.1, Vite 8.3.5, React 플러그인 6.2.1 설치와 배포 빌드가 통과했습니다. 개발 컴퓨터는 Node.js 26.8.1입니다.

React 배포 빌드의 실제 브라우저에서 방향키 순환·비활성 메뉴 건너뛰기·Tab·Enter·Esc·초점 복귀, 클릭으로 오답 복습 안내 열기와 돌아가기를 확인했습니다. 1366×768 및 360×480 창에서 메뉴에 접근할 수 있었고 가로 넘침은 없었습니다. 서로 다른 시점의 캡처로 횃불·망토·선택 표시가 움직이는지 확인했으며, 브라우저 콘솔 오류·경고는 없었습니다. 캡처는 `docs/screenshots/react-*.jpg`에 보관합니다.

플랫폼의 움직임 줄이기 설정에 따른 정지 화면과 숨겨진 탭에서의 일시 정지를 지원합니다. 실제 학교 크롬북·터치패드 하드웨어·학교 네트워크·메모리 사용량은 아직 검증하지 않았습니다.

[기존 이미지 생성 기록](docs/animation-assets.md). React 전환에서는 새 이미지를 생성하지 않았습니다. 이전 Flutter 격자 방식 설명은 당시 작업 기록이며, 현재는 Canvas 2D의 가로 띠 변형 방식입니다.

## 메인 화면 개편 — v0.4

[UI 개편 계획](docs/UI_REDESIGN_PLAN.md)의 시작 화면 방향을 적용했습니다. 좌측은 작은 두 줄 로고와 명확한 메뉴, 우측은 독립된 픽셀 던전 입구 장면으로 구성했습니다. 새 모험을 최상단 기본 선택으로 두고, 저장 기록이 없는 이어하기는 바로 아래 비활성 상태로 표시합니다.

[픽셀 장면과 확인 기록](docs/main-screen-v0.4.md). 새 이미지 생성 도구는 사용하지 않았으며, 벽·문·바닥·용사·망토·횃불을 코드로 구성했습니다. 예전 이미지 자산 기록은 이전 버전의 보관 자료입니다. 전투·학습 문제·결과 화면은 이번 변경에 포함하지 않았습니다.

## 설정 화면 — v0.5

타이틀의 설정 메뉴에서 화면·연출과 조작 안내를 엽니다. 글자 크기(보통·크게·아주 크게), 배경 움직임(기본·줄이기·끄기), 메뉴 선택 효과(천천히 밝아짐·고정)를 즉시 적용하고 같은 브라우저에 자동 저장합니다. 학습 진행 저장과는 별개입니다. 전체 화면은 브라우저가 허용할 때 전환하며 저장 대상이 아닙니다.

배경 움직임을 끄거나 기기의 움직임 줄이기가 켜져 있으면 Canvas 애니메이션을 멈춥니다. 기본값 복원은 화면 설정만 복원하며 다른 저장 데이터는 지우지 않습니다. 저장소를 사용할 수 없으면 이번 접속에서 설정을 유지하고 안내를 표시합니다. 음악·효과음과 전투 관련 설정은 해당 기능을 추가할 때 연결합니다.

`npm test`로 설정 저장·복구, 애니메이션 정리, 메뉴 포커스 복구, 단어 데이터와 티어·검색 테스트 22개를 실행합니다. [설정 화면 구현과 확인 기록](docs/settings-v0.5.md)을 참고하세요.

## 창 전환 후 키보드 입력 복구

기존에는 시작 메뉴 안에 초점이 있을 때만 방향키를 처리해, 창·탭을 옮기거나 배경을 클릭한 뒤 초점이 페이지로 빠지면 조작이 멈췄습니다. 이제 페이지 배경에서도 ↑·↓·Home·End를 누르면 마지막 선택부터 이동하며 메뉴에 초점을 돌려줍니다. Enter·Space도 배경에서 선택한 메뉴를 실행합니다. 설정이나 안내창이 열려 있을 때는 시작 메뉴 입력 처리를 해제하고, 다른 컨트롤의 입력·단축키·한글 조합 중 입력은 가로채지 않습니다.

Safari의 배포 빌드에서 배경 클릭, 다른 창과 탭으로 이동 후 복귀, 방향키 순환, Enter 실행을 확인했습니다. 설정 분류와 라디오 버튼의 방향키 조작, Esc 종료와 마지막 메뉴 초점 복귀도 확인했습니다. `npm test` 16개와 `npm run build`가 통과했습니다.

## 티어별 단어장

타이틀의 ‘단어장’에서 브론즈 64·실버 290·골드 741·플래티넘 969·마스터 1,000개의 누적 범위를 선택합니다. ‘누적 전체’와 ‘해당 티어 추가’ 범위를 전환하고 단어·뜻·유의어·반의어·출처를 검색할 수 있습니다. 항목을 펼치면 어휘 관계와 출처가 나타나며, 목록은 30개씩 표시합니다. 티어는 학습 범위이며 모두 열려 있습니다.

5개 원본 PDF의 모든 표를 추출해 마스터 범위와 행 단위로 대조했습니다. 같은 철자라도 뜻이 다른 항목은 구분하고 원문의 설명·상대어 표시를 유지합니다. [자료와 구현 확인 기록](docs/vocabulary.md).
