# S’word Master 전장 개편 구현 기록

## 전투 재생

- 카드별 준비·타격·효과 완성·복귀 시점을 3D와 Phaser 간편 화면이 공유한다. 전투 화면이 재생기와 타격 번호를 보관하므로 WebGL 오류 뒤에도 간편 화면에서 남은 타격을 이어서 표시한다.
- Kenney 기사 모델의 팔·다리·손목에 카드별 자세를 적용한다. 실제 손목과 칼끝 사이를 샘플링해 잔상을 그리며, 쌍격은 방향과 색이 다른 두 잔상으로 구분한다.
- 표시 체력, 피해·방어 숫자, 타격 정지, 피격 동작, 카메라와 소리는 타격 순번에 맞춰 재생한다. 적의 강타는 다음 행동 패턴을 따르고, 용사 사망 예고와 실제 피해가 같은 방어 계산을 사용한다.
- 일반 전투 기준 기본 베기 0.89초, 강공격 1.395초, 쌍격 1.36초, 노바 1.79초다. 강화와 처치는 해당 타격에 정지 시간이 추가된다.

## 연출과 설정

- 검광, 바닥 균열과 파편, 교차 검광, 파동 투사체, 노바 빛기둥과 충격파를 추가했다. 방어막, 회복 꽃잎, 강화 불씨, 약화 사슬, 집중 별빛, 흐름의 나선, 서약 문장과 왕관을 카드별 시점에 연결했다. 강화형에는 카드별 문양과 추가 충격을 사용한다.
- 검광 마스크와 폭발·연기 연속 프레임은 직접 생성한 자산이다. Pillow 환경에서 `python3 scripts/export_combat_textures.py`로 재생성할 수 있다. Kenney 원본의 CC0 표기는 기존 고지에서 확인할 수 있다.
- 높은 품질은 전투에서 선택적 발광과 높은 잔상·입자 예산을 사용한다. 낮은 품질은 발광 후처리를 끄고 잔상·입자·파편을 줄인다. 움직임 줄이기는 짧은 결과 표시를, 끄기는 즉시 결과 표시를 사용한다.
- 효과음은 Web Audio로 생성하며 브라우저 사용자 입력 뒤 재생한다. 기존 설정 저장 형식에 효과음 켜기·끄기와 0~100% 음량을 추가했다. 이전 설정은 켜짐과 60%로 초기화된다.

## 검증

- `npm test` 85개 통과. 새 타임라인과 GLB 칼끝, 타격 정지, 중복 방지, 쌍격 첫 타격 처치, 기존 저장·설정의 호환성을 확인했다.
- `npm run build` 통과. Vite의 대형 청크 경고가 표시된다.
- `npm run test:3d`에서 일반·강화 카드 24가지, 몬스터 12종의 다단 타격, 완전 방어와 처치, 품질·모션 설정, 탭 숨김과 복귀, 리사이즈 중 3D에서 간편 화면으로 이어지는 두 번째 타격을 확인했다.
- `npm run test:ui`에서 360px 화면과 큰 글자 설정, 학습·오답 복습, 간편 화면과 입체 화면 전환, 패배 결과 및 타이틀 복귀를 확인했다.
- `npm run test:journey`에서 브론즈 모험을 127단계로 완료했다. 퀴즈 도중 새로고침을 거쳐 33문제 정답과 브론즈 클리어, 서약 해금이 저장됐다.
- Chromium에서 쌍격의 준비음과 두 타격이 Web Audio 소리를 발생시키고, 음량 37%와 음소거가 다시 열어도 유지되는 것을 확인했다.
- `node scripts/capture-combat.mjs`로 기본 베기 8장, 쌍격 10장, 노바 9장을 `artifacts/combat-overhaul/`에 저장한다. 로컬 Chromium과 모바일 뷰포트로 확인했다. 실제 휴대폰·학교 PC의 목표 프레임은 측정이 필요하다.
