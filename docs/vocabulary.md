# 티어별 단어장

타이틀의 ‘단어장’ 메뉴에서 여는 화면이다. 화면 이름은 ‘단어장’으로 표시한다. 기존 타이틀의 녹회색 패널, 아이보리 글자, 금색 선택선과 픽셀 문양을 이어간다.

## 범위와 동작

| 티어 | 아래 티어를 포함한 누적 범위 | 해당 티어 추가 |
|---|---:|---:|
| 브론즈 | 64 | 64 |
| 실버 | 290 | 226 |
| 골드 | 741 | 451 |
| 플래티넘 | 969 | 228 |
| 마스터 | 1,000 | 31 |

티어 선택, 누적·추가 범위 전환, 단어·뜻·유의어·반의어·출처 검색을 지원한다. 항목을 펼치면 유의어·반의어 또는 상대어와 출처를 보여준다. 원문의 ‘—’는 제시된 관계가 없다는 안내로 표시한다. 각 목록은 원본 ABC 순서를 유지하며 30개씩 나눈다. 범위나 검색어를 바꾸면 1페이지로 돌아간다.

방향키와 Home·End로 티어를 이동하고, Tab으로 검색과 목록에 접근한다. Enter·Space로 항목을 펼치고 Esc·닫기·돌아가기·배경 클릭으로 타이틀의 단어장 메뉴에 초점을 돌려준다. 입력창과 목록의 키를 타이틀 메뉴가 가로채지 않는다. 작은 화면에서는 티어 목록을 가로로 스크롤한다. 설정의 글자 크기도 적용한다.

## 원자료와 변환

Google Drive에 제공된 고2 10월 모의고사 및 교과서 3·4과 어휘 PDF 5개를 사용했다.

- [브론즈 64개](https://drive.google.com/file/d/1u_icnE_jNAS8SE3XHEUEu402exY8EojF/view)
- [실버 290개](https://drive.google.com/file/d/16PANwqqSVF9eVIo1PseTaJ73qinFNNPf/view)
- [골드 741개](https://drive.google.com/file/d/1xmlZOgEBIof6hkhkl-TbxTj1MoB9hchJ/view)
- [플래티넘 969개](https://drive.google.com/file/d/1gDhwq5OppefKLZNgGLeZkJuwJJKAZnDZ/view)
- [마스터 1,000개](https://drive.google.com/file/d/1yyN3TVh7QwIyy_oC7sIQKklNHaJbSPUs/view)

`scripts/import-vocabulary.py`는 pdfplumber 0.11.10으로 여섯 열(단어·뜻·유의어·반의어·출처·티어)을 추출한다. 원본을 `bronze.pdf`, `silver.pdf`, `gold.pdf`, `platinum.pdf`, `master.pdf`로 저장한 디렉터리를 인자로 전달하면 `src/data/vocabulary.json`을 생성한다. 원본 PDF와 다운로드 인증 URL은 저장소에 넣지 않는다.

모든 누적 파일이 마스터의 해당 부분집합과 순서·전체 필드에서 일치해야 변환에 성공한다. 행 수, 누락 필드와 중복 식별자를 검사한다. 식별자는 단어와 뜻의 해시로 정해 `claim`과 원문의 `claim (주장)` 같은 서로 다른 의미를 보존한다. 줄바꿈을 공백으로 정리하고 출처는 원문의 줄별 배열로 유지한다. 원자료의 어휘 관계를 임의로 추가하거나 고치지 않는다. 이 자료는 조회용이며 퀴즈 정답·오답 선택지를 검수한 결과물이 아니다.

## 확인

- 다섯 PDF: 누적 64·290·741·969·1,000개 전체 행과 필드 일치.
- 자동 테스트 22개: 누적 포함 관계, 추가 범위 분리, 의미별 식별, 범위 내 검색, 기존 설정·애니메이션·메뉴 입력 회귀 확인.
- `npm run build` 통과.
- Safari: 타이틀에서 열기, 방향키로 티어 이동, 단어 검색과 상세 펼치기, 페이지 이동 확인.
- Chromium 기반 브라우저: 누적·추가 범위, 범위 밖 검색의 빈 결과, 상세 설명, 360×600 화면에서 가로 넘침 없음과 마지막 페이지 버튼 비활성 확인. 콘솔 오류·경고 없음.
