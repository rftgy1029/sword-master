# S’word Master 설정 화면 v0.5

2026년 11월 4일, 타이틀과 같은 분위기의 설정 화면 구현.

## 구현한 동작

- 타이틀 위에 열리는 각진 패널. 기존 색상·글꼴·금색 화살표·선택 테두리를 사용한다.
- 화면·연출과 조작 안내를 분리한다. 왼쪽 분류는 방향키로 이동하고, Tab으로 항목을 이동하며 기본 라디오 입력의 방향키·Space 조작을 지원한다.
- 글자 크기: 보통 100%, 크게 115%, 아주 크게 130%. 로고는 유지하고 메뉴·설정·안내 글자 크기를 조절한다.
- 배경 움직임: 기본은 기존 속도, 줄이기는 느린 움직임과 최대 12회/초 갱신, 끄기는 정적 장면. OS 움직임 줄이기는 항상 정적 장면을 우선한다.
- 메뉴 선택 효과: 기존 3.2초 밝기 변화 또는 고정. 같은 패널의 미리보기에 즉시 반영한다.
- 전체 화면: 지원 브라우저에서 전환하고 실패 시 안내한다. 실제 전체 화면 상태를 표시하며 자동 저장하지 않는다.
- 설정은 `sword-master.settings.v1` 키의 버전 1 형식으로 저장한다. 손상·알 수 없는 값은 기본값으로 복구한다. 저장 실패 시 이번 접속 중에 적용하고 안내한다.
- 기본값 복원은 이 설정만 변경한다. 학습 기록이나 다른 앱의 저장 키는 삭제하지 않는다.
- Esc·닫기·돌아가기로 종료하면 타이틀 설정 버튼으로 초점을 돌린다. 설정을 열고 있는 동안 배경 페이지의 스크롤은 잠근다.

음원·전투 기능이 없는 현 단계에서 음악 음량이나 전투 효과를 조절하는 빈 항목은 추가하지 않았다.

## 확인한 범위

- `npm test`: 9개 통과. 설정의 정상 저장·읽기, 누락·손상·버전 불일치·잘못된 값·저장 실패·다른 데이터 보존을 확인한다. 배경 끄기·OS 움직임 줄이기·숨김과 복귀·해제 시 애니메이션 정리도 확인한다.
- `npm run build`와 `git diff --check` 통과.
- 실제 브라우저에서 설정 진입, 큰 글자·움직임·선택 효과의 상태 변경, 글자 크기와 선택 효과 CSS 즉시 반영을 확인했다.
- 새로고침 후 설정을 다시 열어 변경한 세 값의 유지, 기본값 복원, Esc 후 타이틀 설정 버튼 초점 복귀를 확인했다.
- 분류 클릭과 방향키 이동, 조작 안내 열기, 돌아가기를 확인했다.
- 1280×720 및 360×480 크기의 같은 출처 iframe에서 가로 넘침 없이 설정 항목에 접근했다. 작은 화면의 아주 큰 글자에서도 조작 안내와 돌아가기 버튼을 사용할 수 있었다. 이는 창 크기 검증이며 실제 휴대폰·크롬북 하드웨어 테스트는 아니다.
- 미리보기 브라우저에서는 전체 화면 요청이 거부되어 오류 안내 경로를 확인했다. 전체 화면 진입·해제 성공은 실제 지원 브라우저에서 추가 확인이 필요하다.
- 검사 중 보인 브라우저 확장의 메타데이터 전송 오류는 앱 오류와 구분한다. 학교 기기 성능·메모리 사용량은 아직 미측정이다.
