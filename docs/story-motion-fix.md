# 대사 중 행동 반복 수정

대사 한 줄에서 니아의 인사가 두 번, 모모의 점프·충돌 반응이 두 번, 대화 반응과 승리 점프가 세 번 반복되던 문제를 수정했다. 해당 행동은 한 번만 재생하고 마지막 자세를 유지한다. 호흡·횃불 등 배경의 작은 움직임은 계속 재생한다.

대사 번호를 캐릭터의 React 키에 포함해 같은 추격·퇴장 장면에서도 캐릭터가 다시 생성되고 있었다. 이야기에서는 장면 안의 캐릭터를 유지한다. 여러 대사에 걸친 추격·충돌은 동일한 장면 상태를 사용하고, 니아의 퇴장도 대사마다 다시 시작하지 않는다. 실제 새 전투 응답은 응답 토큰과 행동으로 구분해 검격·방어가 각각 한 번 재생되도록 한다.

일시정지 시 일부 동작의 `animation`을 없애던 규칙도 제거했다. 이제 일시정지·장면 목록·탭 숨김은 기존 애니메이션의 재생 상태만 멈춘다. 복귀하면 멈춘 위치에서 이어지고, 이미 끝난 동작은 다시 시작하지 않는다. 움직임 줄이기와 끄기 설정은 그대로 지원한다.

## 재현 및 검증

수정 전 프로덕션 빌드에서 회귀 검사는 `('.actor-nia', 'nia-greet', 2)`로 실패했다. 수정 후에는 다음 브라우저 검사를 통과한다.

```sh
npm run build
npm run preview
# 다른 터미널: Python Playwright와 Chromium 필요
python scripts/check-story-motion.py --chromium /usr/bin/chromium
```

`--url`로 다른 실행 주소를 지정할 수 있다. 테스트는 전용 새 브라우저 컨텍스트에서 실행해 사용자의 기존 저장을 건드리지 않는다.

| 확인 대상 | 결과 |
| --- | --- |
| 인사·대화 반응·점프·충돌 | 행동별 1회 |
| 한 대사에서 실제 점프 종료 이벤트 | 종료 1회, 반복 이벤트 0회 |
| 추격의 4개 대사 | 같은 캐릭터·애니메이션 유지, 완료 후 재시작 없음 |
| 니아 퇴장의 3개 대사 | 퇴장 1회, 완료 자세 유지 |
| 통로 입장 중 일시정지·재생 | 같은 애니메이션과 진행 위치 유지 |
| 완료된 입장 연출 일시정지·재생 | 완료 상태 유지 |
| 장면 목록·탭 숨김 후 복귀 | 기존 애니메이션에서 이어 재생 |
| 전투 6문제의 검격·방어와 승리 | 응답별 1회, 응답 기록 6개·코인 45 유지 |
| 모바일 터치·움직임 줄이기·끄기 | 반복 없음, 가로 넘침 없음 |

단위 테스트 72개와 프로덕션 빌드·Wrangler 배포 드라이런도 통과했다. 기존 해독검의 2초 연출·장면 목록 일시정지·저장 복원 검증을 통과했다. 브라우저 콘솔 오류는 없었다.
