# S’word Master v0.6 — 덱빌딩 전투

## 기존 프로젝트 분석과 보존

수정 전 코드는 React 19 + Vite 8 + JavaScript + CSS였다. Canvas 타이틀의 용사·망토·횃불·던전 입구, 방향키/Enter 메뉴 이동, 설정, 티어별 단어장 1,000개가 구현되어 있었다. 새 모험과 오답 복습은 준비 중 안내였고 이어하기는 비활성이었다. 실행 가능한 전투·퀴즈·학습 기록 저장은 없었다.

타이틀의 레이아웃·로고·색상·폰트·배경 그림을 보존했다. 기존 `styles.css`, `src/settings.js`, `src/menuNavigation.js`, `src/data/vocabulary.json`은 변경하지 않았다. 용사 그리기 함수와 티어 문양만 export해 새 화면에서 재사용한다. 기존 메뉴 이동 함수에 활성 메뉴 배열을 전달해 이어하기도 같은 키로 조작한다. 추가 화면은 기존 dialog 방식으로 타이틀 위에 열린다. 스토리·대사·퀘스트는 추가하지 않았다. 외부 게임의 자산이나 고유 카드도 사용하지 않았다.

## 플레이 흐름

새 모험 → 누적 학습 티어 선택 → 8층 경로 → 전투/강적/보물/휴식/대장간 → 보상 → 보스 → 결과.

- 티어는 브론즈 64·실버 290·골드 741·플래티넘 969·마스터 1,000개다. 모두 열려 있으며 전투 난도는 동일하다.
- 층마다 현재 위치와 이어진 경로 하나를 선택한다. 강적은 선택 사항이고 휴식층에는 회복 경로가 있다. 시작 시 시드로 배치·적·보상을 정하고, 난수 상태도 저장한다.
- 일반 적 3종, 강적 2종, 보스 1종은 공격·방어·힘 증가·강타 준비 패턴을 가진다. 다음 행동과 약화 적용 후 공격 수치를 표시한다. 준비 행동에는 피해가 없고 다음 행동의 기본 피해를 예고한다.
- 휴식은 HP 24 회복과 카드 한 장 무료 강화 중 하나를 선택한다. 대장간에서는 카드 강화 30·유물 강화 45·카드 한 장 구입 35 금화를 사용한다. 대장간의 구입은 방문당 한 번이다.

## 턴과 카드 규칙

HP 72, 12장 시작 덱, 매 턴 3 에너지·5장 드로우. 손에는 최대 10장까지 들 수 있다. 카드에는 비용·효과·일반/희귀/전설 희귀도가 있다. 첫 덱은 검의 궤적 3·돌의 자세 2·균열 베기·쌍월·이슬의 숨·불씨 벼리기·녹슨 봉인·고요한 응시·바람의 손이다.

카드를 고르면 즉시 손에서 제거하고 에너지를 소비한다. 문제를 맞히면 카드 효과를 적용하고, 오답이면 효과 없이 소비한다. 오답/정답 모두 원래 문제·선택한 답·정답·뜻·어휘 관계·출처 해설을 확인한 뒤 계속한다. 미해결 문제/해설이 있는 동안 다른 카드와 턴 종료는 잠긴다. 새로고침과 Esc 후 이어하기에도 비용과 문제가 유지된다. 중복 답변이나 보상 요청은 reducer에서 무시한다.

턴 종료 시 남은 카드를 버리고 적이 예고한 행동을 한다. 플레이어 방어는 그 행동 후 사라진다. 적 방어는 다음 적 행동 시작 때 초기화된다. 약화는 적 행동마다 1턴 감소하며 공격을 25% 줄인다(내림). 빈 드로우 더미는 버린 더미를 섞어 채운다. 소멸 카드는 정오답 모두 그 전투의 덱 순환에서 빠지고 다음 전투에 돌아온다. 소멸이 아닌 카드는 재순환할 수 있다.

카드 강화는 한 번 가능하며 효과 수치를 올린다. 힘은 전투 동안 매 타격의 피해에 더한다. 집중은 다음에 성공한 카드의 피해/방어/회복/힘/약화 수치에 더한 뒤 소비한다. 집중 카드끼리는 누적된다. 오답은 집중을 소비하지 않는다. 이슬의 숨과 바람의 손 등 회복·무료 드로우 카드는 소멸해 무한 순환을 막는다.

카드는 총 12종이며 전투 보상은 3장 중 한 장 또는 건너뛰기다. 불멸의 서약은 첫 보스 승리 후 다음 모험의 보상/상점에 해금된다. 일반 적 금화 25, 강적 45, 보물 20은 보상 화면 진입 시 한 번 지급된다.

## 유물과 시너지

유물 6종은 전투 시작 방어, 3연속 정답 추가 피해, 첫 공격 강화, 연속 공격 추가 타격 강화, 매 턴 첫 비공격 카드의 에너지 회복, 보스 입장 회복을 제공한다. 각각 Lv.2 강화가 있다. 유물 목록에서 효과를, 대장간에서 강화 후 효과를 확인할 수 있다.

쌍월 + 메아리 고리, 힘 증가 + 연속 공격, 집중 + 힘/방어, 첫 공격 강화 + 고위력 공격, 비공격 카드 + 푸른 샘 등으로 덱의 방향을 정할 수 있다. 처음 얻는 유물을 우선 제시하고 전부 보유했다면 미강화 유물의 강화를 제시한다.

## 퀴즈와 학습 기록

현재는 뜻의 선택지 그룹과 관계 문제의 오답 선택지를 직접 만든 72개 단어·120개 문제를 사용한다.

| 티어 | 누적 출제 단어 | 문제 수 |
| --- | ---: | ---: |
| 브론즈 | 40 | 56 |
| 실버 | 48 | 72 |
| 골드 | 56 | 88 |
| 플래티넘 | 64 | 104 |
| 마스터 | 72 | 120 |

뜻·유의어·반의어를 모두 지원하며 원자료에 제시된 유효한 정답을 모두 판정에 반영한다. 표시 선택지는 정답 하나와 오답 셋이며, 원자료의 다른 유효 정답을 오답으로 넣지 않는다. 상대어·미기재·의미가 번호로 구분된 관계는 자동으로 문제화하지 않는다. 관계 문제에는 원문의 뜻을 함께 표시한다. 전투에서는 새 단어를 우선 출제하고 같은 단어/유형 조합은 출제 풀을 전부 소진하기 전에는 반복하지 않는다.

문제별 풀이·정답·오답 횟수와 연속 정답, 약점 여부를 기록한다. 오답은 약점으로 남고 해당 문제를 두 번 연속 맞히면 복습 완료가 된다. 완료 후에도 기록은 삭제하지 않는다. 복습 정답은 전투 HP·에너지·카드에 영향을 주지 않는다. 패배와 새 모험은 학습·약점·클리어·해금 기록을 유지하고 임시 덱·유물만 초기화한다.

## 저장과 오류 처리

- 새 키 `sword-master.adventure.v1`에 버전이 있는 모험·학습·복습 스냅샷을 함께 쓴다. 기존 설정 키와 다른 저장 키를 삭제/변환하지 않는다.
- 사용자 입력 이벤트에서 reducer를 실행하고 동기 저장한 뒤 화면을 갱신한다. React effect의 나중 저장에 의존하지 않는다. reducer는 저장 부작용이나 시각에 의존하지 않아 StrictMode에서도 효과를 중복 적용하지 않는다.
- 복구 시 타입·수치·경로·소유 카드·더미 분할·유물·선택지·학습 집계를 검증한다. 모르는 버전/손상 데이터는 원본 그대로 두고 안내하며, 그 접속에서는 메모리에서만 진행한다.
- 저장 접근 거부/용량 초과는 안내한다. 다른 탭이 이전 스냅샷을 바꿨다면 덮어쓰기와 해당 탭의 후속 행동을 막고 새로고침을 안내한다. 서버 동기화나 여러 탭의 동시 플레이 병합은 지원하지 않는다.
- 보스/패배 결과에는 도전 요약을 남기고 전투용 덱·유물을 정리한다. 결과가 끝난 기록은 이어하기 대상이 아니다.

## 검증

1. 핵심 전투: HP·턴·방어/약화·에너지·드로우·소멸·정답/오답·중복 입력 방지·시너지·패배/기록 보존 검사.
2. 덱빌딩: 카드/유물 보상 단일 획득·건너뛰기·강화 비용과 중복 강화 방지·상점 1회 구입 검사.
3. 로그라이크: 300개 시드의 재현성·경로 연결·회복 선택·선택적 강적, 보스 클리어/해금 검사. 5개 티어×3개 시드에서는 실제 턴·드로우 규칙으로 끝까지 진행하며 매 행동을 저장/복구한다.
4. 완성도: 기존 메뉴/설정/장면/단어장 회귀, 손상/지원하지 않는 저장/저장 거부/탭 충돌 검사. Chromium UI에서 티어·전투·오답·복습·이어하기·강적·보상·카드/유물 강화·구입·보스 결과 확인. 1366×900, 360×640, 360×480 및 큰 글자에서 가로 넘침 검사. 콘솔 오류·경고 없음.

자동 검사: 45개 통과. `npm test` 및 개별 검사 결과가 보이는 `node --test --test-isolation=none --test-reporter=spec`(Node 22.8+)을 실행했다. `npm run build` 통과. 브라우저 캡처는 `docs/screenshots/deckbuilding-*.png`에 있다. 검증용 브라우저는 새 격리 컨텍스트를 사용해 실제 사용자 저장 데이터를 건드리지 않았다. Git push나 외부 배포는 하지 않았다.

## 남은 범위

나머지 단어의 문제화, 실제 학생 대상 난도·보상 밸런스 검증, 실기기 터치/학교 브라우저 검증은 남아 있다. 현재 전투는 적 한 체와의 전투이며 카드의 적 선택이나 여러 적 동시 전투는 없다. 음악/효과음, 계정과 기기 간 동기화는 구현하지 않았다. 스토리·대화는 요청에 따라 포함하지 않는다.

주요 코드: `src/game/engine.js`(규칙), `catalog.js`(콘텐츠), `quiz.js`(출제), `storage.js`/`useProgress.js`(저장), `src/components/AdventureDialog.jsx`(게임 화면), `QuizPanel.jsx`/`ReviewDialog.jsx`(학습), `CombatScene.jsx`(장면), `adventure.css`(스타일). 새 자동 검사는 `test/game.test.js`, `dungeon.test.js`, `quiz.test.js`, `progress.test.js`에 있다.
