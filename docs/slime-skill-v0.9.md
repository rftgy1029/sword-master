# S’word Master v0.9 — 첫 슬라임전의 해독검

이 문서는 이전 자동 공격·종결 연출의 기록입니다. 현재 수동 발동과 체력 규칙은 [액티브 해독검](active-decode.md)을 참고하세요.

## 플레이

‘게임 시작 → 브론즈’에서 지하 통로까지 진행합니다. 바로 확인하려면 이야기 하단의 ‘장면 목록 → 전투·마법 퍼즐 바로가기 → 통로의 작은 슬라임’을 선택합니다.

- 정답: 준비 0.3초 → 돌진 0.2초 → 타격 0.25초 → 복귀 0.45초. 몸통·망토·다리·팔·검을 나눠 움직이며, 접촉 순간 약 0.07초 멈추고 슬라임이 찌그러지며 밀려납니다.
- 오답: 슬라임이 달려들고 용사가 검으로 막습니다. 정답 뜻을 함께 표시합니다.
- 네 문항의 뜻을 확인한 뒤 ‘결과 보기’: 0.6초 용사 컷인과 기술명에 이어 강화 베기, 전체 1.8초의 마무리가 나옵니다. 오답도 뜻을 확인하므로 마지막 공격은 정답 점수와 별개입니다.
- ‘다음 문제’를 누르면 남은 공격 연출을 종료하고 진행합니다. 마무리는 ‘연출 건너뛰고 결과 보기’로 생략합니다.
- 자동 진행은 모션 완료 후 정답 피드백 2.2초, 오답 피드백 4.5초를 기다립니다. 자동 진행을 끄면 다음 문항을 직접 선택합니다.

## 소리·움직임·저장

설정의 ‘전투 효과음’에서 검격·타격·방어 소리를 켜거나 끕니다. 기본은 켜기입니다. 효과음은 Web Audio로 직접 생성하며, 첫 답변/감상 버튼의 입력에서 오디오를 활성화합니다. 소리가 차단되거나 지원되지 않아도 진행합니다.

‘배경 움직임’의 줄이기·끄기와 기기의 움직임 줄이기를 따릅니다. 이때 이동·흔들림·컷인은 생략하고 정적 효과를 짧게 표시합니다. 장면 목록 또는 다른 탭에서는 단일 재생 시간표를 멈추고 재개합니다. 장면 이동 시 남은 애니메이션·소리를 정리합니다.

응답은 선택 즉시 한 번 저장하고, 모션 상태는 저장하지 않습니다. 새로고침하면 저장된 다음 문항 또는 결과 화면으로 돌아가며 지나간 공격이나 컷인을 재생하지 않습니다. 기존 v1 설정에는 효과음 기본값만 추가하고 학습·이야기 저장 형식은 유지합니다. 첫 슬라임전만 새 연출을 사용하며, 다른 전투와 퍼즐은 기존 방식입니다.

## 구현과 검증

`slimeSkill.js`의 단일 시계가 Web Animations API의 각 동작과 효과음 시점을 함께 진행시킵니다. 전투는 스킬 종류와 고유 재생 식별자를 보내고, 완료 통지를 받은 뒤 자동으로 진행합니다. 같은 시계를 멈추므로 숨겨진 화면에서 효과음만 먼저 진행하지 않습니다.

단위 테스트는 재생 일시정지·재개, 취소 후 남은 소리/완료 통지 차단, 모션 줄이기의 짧은 완료, 차단된 오디오와 기존 설정 호환을 확인합니다. 브라우저에서는 공격·방어·컷인, 연출 건너뛰기, 재도전·저장 복귀, PC·모바일, 효과음과 모션 설정, 기존 전투·퍼즐을 확인합니다.

검증 명령: `npm test`, `npm run deploy:check`. 실제 배포는 하지 않는 사전 검사입니다.
