# S’word Master — 전장 경험 개편 명세

2026-11-13에 받은 전투 개편 요구사항을 보관한 문서다. 이동·타격감·12종 스킬·카메라·사운드·성능·검증의 기준이며, **이 문서가 있다고 해서 구현이 끝났다는 뜻은 아니다.** 실제로 구현하고 확인한 내용은 [전장 개편 구현 기록](combat-overhaul-implementation.md)에 따로 적는다. 공통 작업 기준은 [AGENTS.md](../AGENTS.md)를 따른다.

## 목표

공격할 때마다 동작의 목적과 힘이 느껴지고, 스킬마다 서로 다른 시각적 개성과 리듬을 갖는 전투. 용사의 이동부터 12종 스킬 이펙트, 타격감, 카메라, 사운드, 적의 반응까지 구현하고 검증한다.

최종적으로 용사의 움직임에는 접지와 목적이 느껴지고, 각 스킬은 자기만의 형태와 리듬을 가지며, 충돌 순간에는 동작·빛·소리·카메라·적의 반응이 정확하게 맞아야 한다.

추가 요청: 성능 제한을 풀고 초고사양 그래픽으로 전체를 개편한다. UI도 아름다운 그래픽으로 만든다. (품질 단계와 대상 기기의 목표 프레임은 AGENTS.md의 "성능과 자산 관리"를 따른다.)

## 1. 프로젝트와 기존 구조 확인

- AGENTS.md를 읽고 프로젝트 지침을 따른다.
- React + Vite + JavaScript + CSS, Three.js + React Three Fiber 기반의 기존 구조를 활용한다.
- CombatPlayback, combatPose, attackAnimationTime, Actor, SkillEffects와 공격 타임라인을 먼저 확인한다.
- 개편 전 코드에서 확인된 문제
  - 용사가 이동·복귀할 때도 공격 애니메이션을 재생해 발이 미끄러지는 느낌이 든다.
  - 적이 실제 타격 전에 피격 동작을 시작한다.
  - 공격 카드의 연출 시간이 모두 2초로 고정되어 있다.
  - 쌍격은 두 번의 피해에 대응하는 실제 무기 동작이 부족하다.
  - 이펙트가 얇은 링과 작은 입자 중심이라 존재감이 약하다.
  - 3D 전투에 타격 순간의 짧은 정지와 효과음이 부족하다.

## 2. 전체 비주얼 방향

현재 기사와 던전의 형태에 어울리는 애니메이션풍 판타지 전투.

- 굵고 선명한 검광
- 실제 검의 움직임을 따라가는 잔상
- 색과 형태가 분명한 마법 효과
- 과장된 충격파와 방향성 있는 파편
- 밝은 핵심부와 부드러운 발광
- 충돌 후 짧게 남는 불씨·먼지·빛의 잔향

모든 스킬은 ‘준비 → 발동 → 충돌 또는 효과 완성 → 잔향 → 복귀’의 흐름을 가진다. 각 단계의 크기·밝기·속도를 다르게 하고, 가장 중요한 순간에 효과가 집중되게 한다. 화면에서 캐릭터와 적의 행동을 읽을 수 있어야 한다.

## 3. 용사의 이동과 공격 모션

근접 공격의 흐름:

- 몸을 낮추거나 무기를 당기며 힘을 모은다.
- 발로 바닥을 차며 짧고 빠르게 돌진한다.
- 적과 적절한 간격에서 발을 디디고 공격한다.
- 공격 방향으로 몸과 무기가 자연스럽게 따라간다.
- 자세를 회수한 뒤 적을 바라보며 백스텝으로 복귀한다.
- 복귀 후 대기 자세로 부드럽게 연결한다.

이동 거리, 가속·감속, 발동작, 몸의 기울기, 무기 동작을 맞춰 발이 바닥에서 미끄러지는 느낌을 줄인다.

기본 베기·강공격·쌍격은 준비 자세와 공격 궤적을 구분한다. 쌍격은 실제로 서로 다른 방향의 공격을 두 번 수행하고, 두 타격 시점 모두 무기 접촉과 맞아야 한다.

원거리 스킬은 제자리에서 힘을 모아 발사하는 별도의 시전 자세를 사용한다. 방어·회복·강화도 각 효과에 맞는 자세를 연결한다.

## 4. 타격 순간의 피드백

하나의 타격 이벤트를 기준으로 아래 요소를 정확하게 동기화한다.

- 무기 또는 투사체의 접촉
- 적의 피격 동작 시작
- 짧은 타격 정지
- 충돌 섬광과 불꽃·파편
- 충돌음
- 카메라 반응
- 표시 체력과 피해 숫자

적은 실제로 맞는 순간부터 반응하고, 맞은 방향으로 밀리거나 몸이 꺾인 뒤 자세를 회복한다.

타격 정지의 초기 조정값:

- 기본 공격: 약 40~60ms
- 강공격: 약 80~100ms

타격 정지는 연출에 적용하고, UI·퀴즈·입력 처리 전체를 멈추는 방식은 피한다. 짧은 정지 후 동작이 자연스럽게 이어져야 한다.

피해 숫자는 타격 지점 근처에 나타나고, 다단 공격은 각 타격을 구분해서 보여 준다. 방어된 공격에는 방패 반응·방어음·방어 표시를 제공한다.

## 5. 12종 스킬 연출

각 스킬은 색뿐 아니라 형태·움직임·속도·소리로 구분되어야 한다.

| 스킬 | 요구 연출 |
| --- | --- |
| ① 기본 베기 / strike | 빠르고 넓은 사선 초승달 검광 · 검 끝의 짧은 빛 잔상 · 접촉 지점의 금빛 불꽃 · 짧고 선명한 반동과 베기 소리 |
| ② 강공격 / heavy | 깊게 힘을 모으는 준비 자세 · 검에 모이는 주황빛 에너지 · 크고 무거운 내려찍기 · 접촉 순간의 강한 정지와 낮은 충격음 · 바닥 균열 표현, 퍼지는 충격파, 돌 파편과 먼지 · 적의 큰 반동과 무게감 있는 자세 회복 |
| ③ 쌍격 / twin | 서로 반대 방향으로 이어지는 두 번의 실제 공격 · 청색·보라색 교차 검광 · 각 타격에 맞는 별도의 폭발·소리·피해 표시 · 두 번째 공격에 더 강한 반동 · 마지막에 잠깐 남는 X자 잔상 |
| ④ 파동 / flare | 검 또는 손에서 에너지가 모이는 준비 효과 · 회전하는 에너지 탄이나 검기 · 발사체를 따라가는 긴 꼬리와 입자 · 적에게 도착하는 순간 확산 폭발 · 발사·비행·충돌을 구분하는 소리 |
| ⑤ 노바 / nova | 빛과 입자가 중심으로 빨려 들어가는 충전 · 폭발 직전의 짧은 정적 · 거대한 빛기둥과 확장하는 충격파 · 밝은 중심부, 외곽 에너지, 파편의 여러 층 · 강한 충돌음과 짧은 카메라 반응 · 폭발 후 서서히 사라지는 잔광 |
| ⑥ 방어 / guard | 발밑에 나타나는 문양 · 솟아오르는 방패 조각 또는 돌 조각 · 조각이 합쳐지며 완성되는 방어막 · 테두리를 따라 순환하는 빛 · 완성 순간의 분명한 소리와 자세 |
| ⑦ 회복 / heal | 발밑의 꽃잎 또는 생명 문양 · 위로 흐르는 부드러운 빛 · 몸으로 모이고 흡수되는 회복 입자 · 밝아졌다 가라앉는 따뜻한 발광 · 회복 수치와 맞는 맑은 소리 |
| ⑧ 강화 / empower | 검과 갑옷을 감싸는 불꽃 · 위로 솟는 불씨와 에너지 · 힘이 몸에 들어오는 순간의 발광 · 강해졌다는 느낌의 자세와 소리 |
| ⑨ 약화 / weaken | 적을 둘러싸는 봉인 고리 · 조여드는 사슬 또는 문양 · 어두운 파편과 에너지의 수축 · 봉인이 완성되는 순간의 반응과 소리 |
| ⑩ 집중 / focus | 주변에 흩어진 빛이 검 끝 또는 몸의 중심으로 수렴 · 점점 정렬되는 고리와 입자 · 완성 순간의 날카로운 별빛 · 집중을 나타내는 명확한 자세와 음색 |
| ⑪ 흐름 / flow | 몸을 휘감는 나선형 바람 · 길게 흐르는 청록색 잔상 · 부드럽지만 빠른 회전과 상승 · 가볍게 스쳐 지나가는 바람 소리 |
| ⑫ 서약 / oath | 발밑에 펼쳐지는 대형 문장 · 위로 나타나는 금빛 검 또는 왕관 형상 · 문장에서 캐릭터로 전달되는 빛 · 완성 순간의 장엄한 발광과 소리 · 잠깐 유지되다가 사라지는 문장의 잔향 |

강화 카드에는 기본 효과를 확장한 추가 검광·두 번째 충격파·특별한 마무리 문양 등을 적용한다. 강화 전후가 한눈에 구분되어야 한다.

## 6. 이펙트 구현 방식

전용 이미지 소재와 3D 효과를 함께 활용한다.

- 검광·폭발·연기: 전용 텍스처와 연속 이미지 애니메이션
- 검 잔상: 실제 검 끝의 이동 경로를 따라 생성되는 빛의 띠
- 충격파·파편·투사체: 방향과 공간감을 가진 3D 효과
- 발광: 밝은 핵심 부위 중심의 선택적인 번짐
- 입자: 발산·수렴·상승·회전 등 스킬 목적에 맞는 움직임

잔상은 순간이동·복귀·새 공격 시작 사이에서 끊어 처리해 원치 않는 긴 선이 생기지 않게 한다. 필요한 소재는 기존 자산을 확인한 뒤 재사용하거나 제작하고, 실제 게임에서 로드되는 리소스로 연결한다.

## 7. 카메라와 사운드

카메라 반응에는 강약을 준다.

- 기본 공격: 짧고 미세한 충격
- 강공격: 내려찍는 방향을 느끼게 하는 반응
- 노바: 충전 중 절제된 접근과 폭발 순간의 반응
- 회복·집중: 안정적인 구도

흔들림은 짧고 빠르게 감쇠시키고, 연출 종료 후 원래 구도로 정확하게 복귀한다. UI와 퀴즈의 가독성을 유지한다.

사운드는 준비음·휘두름 또는 발사음·충돌음·잔향을 구분한다. 스킬의 성격에 맞는 음색과 저음의 무게감을 사용하고, 다단 공격의 소리도 각 타격에 맞춘다. 브라우저의 오디오 재생 조건을 처리하고, 효과음 끄기와 음량 조절이 가능하게 한다. 여러 효과가 겹칠 때 과도한 음량이나 소리의 끊김이 생기지 않게 한다.

## 8. 공격 속도와 긴장감

공격별로 다른 길이와 리듬을 적용한다. 초기 목표:

- 기본 베기: 약 0.7~0.9초
- 강공격·쌍격: 약 1.1~1.4초
- 노바: 약 1.5~1.8초

이 값은 출발점이며 실제 동작을 보면서 조정한다. 공격별 길이를 바꿀 때 타격 시점·애니메이션·복귀·입력 잠금 해제를 함께 맞춘다.

적의 강공격은 무기를 드는 자세·모이는 빛·예고음으로 긴장을 쌓는다. 기존 다음 행동 표시와도 일치해야 한다. 처치 순간에는 별도의 무너짐·소멸·파편과 마무리음을 제공한다. 강한 마무리 연출은 중요한 순간에 집중해 반복 전투의 속도를 유지한다. 퀴즈가 나타나면 큰 효과와 카메라 움직임이 가라앉아 문제를 읽고 답하는 데 집중할 수 있어야 한다.

## 9. 게임 규칙과 접근성 유지

- 기존 피해량, 카드 효과, 에너지, 문제, 보상, 티어, 저장 규칙을 유지한다.
- 실제 전투 상태와 시각적인 연출 상태의 책임을 분리한다.
- 연출 때문에 피해가 중복 적용되거나 타격이 누락되지 않게 한다.
- 프레임이 건너뛰어도 각 타격 콜백은 정확히 한 번 실행되어야 한다.
- 같은 effect ID를 다시 재생하지 않는다.
- 치명타, 적 처치, 플레이어 사망, 턴 종료가 정확하게 완료되어야 한다.
- 탭 숨김·복귀, 창 크기 변경, 장면 전환 중에도 상태가 꼬이지 않아야 한다.
- 움직임 줄이기·끄기 설정과 시스템의 모션 감소 설정을 존중한다.
- 감소 모드에서도 타격·방어·회복 결과는 분명히 전달한다.
- 3D 실패 시 기존 2D 화면으로 복구되는 흐름을 유지한다.

## 10. 성능과 자원 관리

- 품질 설정에 따라 입자·파편·잔향·발광 강도를 조정한다.
- 낮은 품질에서도 핵심 검광·투사체·충돌 타이밍은 유지한다.
- 동시에 활성화되는 입자와 조명 수를 제한한다.
- 가능한 곳에서 객체 재사용·풀링·인스턴싱을 활용한다.
- 프레임마다 불필요한 객체와 재질을 생성하지 않는다.
- 텍스처·지오메트리·재질·오디오 자원을 적절하게 정리한다.
- 스킬을 반복 사용해도 메모리와 렌더링 비용이 계속 증가하지 않게 한다.
- 실제 대상 기기에서 확인하지 못한 성능은 확인한 것처럼 보고하지 않는다.

## 11. 작업 순서

1. 기본 베기에서 이동·접촉·타격 피드백·복귀의 기준을 완성한다.
2. 강공격과 노바로 무게감과 화려함의 기준을 완성한다.
3. 쌍격의 두 번의 동작과 타격을 맞춘다.
4. 나머지 스킬과 강화형 전체에 전용 연출을 적용한다.
5. 적 공격·방어·처치·플레이어 사망을 연결한다.
6. 실제 전투와 퀴즈 흐름에서 조정하고 성능을 확인한다.

## 12. 검증과 완료 보고

- 일반·강화 카드 12종 전체를 실제 브라우저에서 확인한다.
- 근접 공격의 접촉 위치와 쌍격의 두 타격을 확인한다.
- 적의 단일·다단 공격, 완전 방어, 처치, 플레이어 사망을 확인한다.
- 움직임 감소·끄기, 낮은 품질, 모바일 화면, 연출 중 크기 변경을 확인한다.
- 3D 실패 후 2D 복구를 확인한다.
- 실제 게임에서 카드 선택 → 퀴즈 → 정답 → 스킬 → 피해 표시 → 다음 행동의 흐름을 확인한다.
- 기존 테스트와 빌드를 실행하고, 바뀐 타이밍에 맞춰 필요한 테스트를 수정한다.
- 타격 횟수·순서·중복 방지·완료 처리 등 중요한 동작을 검증한다.
- 움직임을 판단할 수 있는 짧은 영상이나 연속 캡처를 남긴다.

완료 후에는 실제로 바뀐 부분, 검증 결과, 결과물 위치, 남아 있는 한계를 간결하게 보고한다.
