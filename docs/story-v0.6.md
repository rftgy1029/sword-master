# 브론즈 이야기 — v0.6

이 문서는 최초 스토리 감상 구현 기록입니다. 현재는 [v0.7 연출·전투 개편](bronze-combat-v0.7.md)을 적용해 자동 진행, 실제 단어 전투와 학습 기록을 지원합니다.

타이틀의 **게임 시작 → 브론즈**를 선택하면 첨부 문서의 제1장 ‘던전에 오신 걸 환영합니다!’가 바로 열립니다. 기존 시작 화면은 메뉴 이름과 이어보기 연결을 제외하고 유지합니다. 다른 네 티어는 이야기 자료가 없어 준비 중으로 표시합니다. 학습 티어를 승급·해금 조건으로 사용하지 않습니다.

## 원문과 구현 범위

자료: `Sword_Master_1장_대사중심_전체확장_수정본.docx`.

- S01~S08의 대사와 상황 묘사 316줄을 데이터로 분리했습니다. 원문의 인물·내레이션 인용 대사 252개를 모두 유지합니다.
- 문서의 구현 지시, 기획 표, 장면 목표, 개발 메모는 화면에 표시하지 않습니다. 퀴즈 제안 7곳은 이야기 감상을 위한 짧은 사건 묘사로 바꿨습니다.
- 입구는 기존 Canvas 장면을 재사용합니다. 축제 광장·무대 뒷길·보스 무대·축제 이후 광장은 SVG 픽셀 장면입니다. 등장 전 모모와 엔딩의 녹화 화면은 미리 드러내지 않습니다.
- 보스 승리와 가면 조각은 이야기 속 사건입니다. 실제 전투·단어 응답·학습 성과·보상·승급 기록은 생성하지 않습니다. 완료 화면도 ‘이야기 끝’으로 표시합니다.
- 다음 장인 팔레트 마법학교는 예고만 있습니다. 제공되지 않은 후속 이야기를 만들지 않았습니다.

## 조작과 저장

- ‘다음 대사’·‘이전 대사’, Enter·Space·좌우 방향키로 읽습니다. 버튼에 초점이 있으면 Enter·Space는 해당 버튼을 실행합니다.
- 장면 목록에서 8개 장면으로 자유롭게 이동하거나 현재 장면을 건너뛸 수 있습니다. 마지막 장면에서는 건너뛰기가 비활성화됩니다.
- Esc는 열린 장면 목록을 닫고, 목록이 없으면 타이틀로 돌아갑니다. 티어 선택에서는 Esc로 닫습니다.
- `sword-master.story-progress.v1`에 이야기 버전·티어·장면·줄 번호·감상 완료 여부를 저장합니다. 설정·학습 저장 키와 별개입니다. 스토리에 들어간 뒤부터 ‘이어보기’가 활성화됩니다.
- 새로고침 후 이어보기, 이야기 처음부터 다시 보기, 손상되거나 오래된 기록 복구를 지원합니다. 저장 공간 사용이 차단되면 안내를 표시하고 같은 접속 중 메모리에서 이어봅니다.
- 글자 크기와 배경 움직임 설정을 적용하고, 기기의 움직임 줄이기를 존중합니다.

## 데이터 갱신

첨부 원본은 저장소에 포함하지 않습니다. 원본 DOCX가 있을 때 다음 명령으로 데이터를 다시 추출할 수 있습니다.

```sh
python scripts/import-story.py '/absolute/path/to/Sword_Master_1장_대사중심_전체확장_수정본.docx'
```

`src/data/bronze-story.json`에서 문구를 직접 수정할 수도 있습니다. 장면·줄 구조를 바꾸면 기존 감상 위치가 달라질 수 있으므로 데이터의 `id`도 갱신하세요.
