# S’word Master 메인 화면 v0.4

2026-11-03, 사용자 요청에 따른 시작 화면 개편.

## 시각 규칙

- 좌측: 작은 검 표식과 두 줄 로고, 새 모험 → 이어하기(비활성) → 단어장 → 오답 복습 → 설정.
- 우측: 벽·문·바닥을 갖춘 작은 던전 입구와 용사 전신. 큰 배경 일러스트를 화면 전체에 깔지 않는다.
- 384×288의 픽셀 격자를 기준으로 Canvas 2D에 그린다. CSS `image-rendering: pixelated`로 크기를 조절하고, 로고와 메뉴의 작은 검·화살표도 단순한 형태로 맞춘다.
- 바탕 #151919, 패널 #252C2B, 본문 #EEEBDD, 강조 #D3AE63. 본문과 메뉴는 고딕체, 로고는 굵은 세리프체.
- 메뉴 버튼 높이는 52px, 본문 메뉴 글자 18px. 선택은 화살표·테두리·왼쪽 강조선으로 표시한다.
- 선택된 배경과 테두리는 3.2초 주기로 조금씩 밝기를 바꾼다. 글자는 사라지지 않는다.

## 장면 구조와 움직임

`src/scene.js`에서 정적인 석벽·문·바닥을 한 번 만들어 재사용한다. 용사는 별도로 그리며, 어깨와 발은 고정한 채 망토 끝만 원본 격자의 한 칸 범위로 흔든다. 작은 횃불과 불씨도 별도 단계로 그린다. 새 비트맵 이미지를 생성하거나 외부 게임 자산을 가져오지 않았다.

Canvas 루프는 최대 약 24회/초로 그리도록 제한한다. 이는 구현 상한이며 실제 크롬북의 측정 성능이 아니다. 탭 숨김·AbortController 정리는 기존 구조를 유지하고, 움직임 줄이기 요청 시 정적 프레임을 표시한다.

기존 `assets/images`는 보관하지만 현재 시작 화면에서는 참조하지 않는다. 새 빌드의 출력에 예전 배경 PNG는 포함되지 않았다.

## 확인한 범위

- `npm run build` 성공, `git diff --check` 통과.
- 실제 브라우저에서 위/아래 순환, 비활성 이어하기 건너뛰기, Tab → 단어장 → Enter 안내창, Esc 후 단어장 초점 복귀를 확인했다.
- 클릭으로 오답 복습 안내창을 열고 돌아가기 후 복귀했다.
- 1280×720에서는 전체 페이지 높이 720px, 하단 안내 끝은 692px로 화면 안에 들어왔다. 1366×768에서도 좌우 배치가 정상 표시됐다.
- 360×640 창에서는 메뉴와 장면이 세로로 이어지며 가로 넘침이 없었다. End·Enter로 설정 안내창에 접근했다.
- 다른 시점의 1366×768 캡처를 비교해 망토·횃불·선택 영역의 변화와 지정한 석벽 영역의 고정을 확인했다.
- 브라우저 콘솔 오류·경고가 없었다.
- 실제 학교 크롬북·터치패드 하드웨어·메모리·프레임률은 미측정이다. 움직임 줄이기와 탭 숨김 처리는 코드 확인이며, 이번 브라우저 검사에서 설정 변경 실측을 하지는 않았다.
