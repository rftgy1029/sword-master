# S’word Master 맵 에셋

이 폴더의 맵은 Tiled에서 편집하는 배경 에셋이다. 타이틀과 전투 화면에서 Phaser로 불러온다.
각 `.tmj` 파일과 같은 이름의 `-tiles.png` 이미지를 함께 보관해야 한다.

- `dungeon-entrance.tmj`: 메인화면용 던전 입구 배경. 384×288px, 타일 16×16px.
- `battle-ancient-hall.tmj`: 고대 석조 전당 전투 배경.
- `battle-forgotten-library.tmj`: 잊힌 서고 전투 배경.
- `battle-ember-forge.tmj`: 잿불 대장간 전투 배경.

전투 배경은 모두 384×224px, 타일 16×16px이다. 바닥 시작 위치는 y=192px(화면 높이의 약 86%)로 맞췄다. 배경과 건축·조명은 별도 레이어이며, `Markers`는 비어 있는 오브젝트 레이어다. 전투 배경의 타일셋은 해당 배경을 타일로 나누고 같은 타일을 중복 제거한 것으로, 범용 조립식 타일셋보다는 해당 화면 수정에 적합하다. `-preview.png`는 확인용 이미지다.

전투 배경은 적 종류에 따라 고정되며, 원본 비율을 유지해 표시한다. 넓은 화면에서는 좌우로 맵을 반복해 빈 공간을 채운다. 적별 배경 선택은 `src/game/mapAssets.js`에서 변경할 수 있다.
